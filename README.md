# Straight Lines — мини-приложение для Telegram

Мини-приложение по сайту https://www.sl-ls.ru. Все тексты, цены, артикулы и контакты взяты с сайта.

## Что внутри

```
app/                  ← само приложение (эту папку выкладываем на хостинг)
  index.html
  css/app.css         ← стили: цвета бренда, шрифты GOST type A + Arsenal SC
  js/content.js       ← тексты: услуги, помощь, контакты, о бренде (правятся вручную)
  js/catalog.js       ← каталог: 39 выкроек, виды одежды, уровни (сгенерирован с сайта)
  js/app.js           ← логика приложения
  img/p/, img/t/      ← фото товаров (большие и превью), формат webp
  img/ui/             ← логотип, фото для «О бренде»
  fonts/GOST_A.ttf
tools/serve.mjs       ← локальный сервер для просмотра
tools/pipeline/       ← скрипты, которыми собраны данные и картинки с сайта
sl-phto/_переименования.csv ← журнал переименования фото (старое имя;новое имя)
```

## Разделы

- **Каталог** — 4 уровня (Новичок / Специалист / Эксперт / Все сразу). Уровень раскрывается и показывает виды одежды с фото, дальше список выкроек с переключателем видов и карточка товара: галерея, выбор роста и размера, описание, оплата, доставка, возврат, корзина. Есть поиск.
- **Услуги** — 7 услуг с сайта; кнопка «Оставить заявку» открывает Telegram @straightlines.
- **Помощь** — 7 вопросов; по нажатию открывается ответ на сайте. Ниже ссылки «Оплата / Доставка / Возврат».
- **Контакты** — почта, Telegram, телефон, «О бренде», реквизиты, документы.
- **Корзина и заказ** — заказ собирается в текст; его можно отправить в Telegram или на почту. Онлайн-оплаты пока нет.

## Как посмотреть на компьютере

```bash
node tools/serve.mjs
```

Потом открыть http://localhost:5173. Прямые ссылки: `?startapp=p_takka` (товар), `?startapp=s_3d-scan` (услуга), `?startapp=l_novice` (уровень).

## Где работает

- Сайт: https://suvbruce67.github.io/sl-miniapp/ (GitHub Pages, обновляется сам после каждого push в `main`)
- Бот: [@straightlines_bot](https://t.me/straightlines_bot), кнопка меню «Каталог»
- Картинка 640×360 для BotFather: `bot/miniapp-640x360.png`

## Как подключить к Telegram

1. Выложить папку `app/` на любой хостинг с HTTPS (GitHub Pages, Netlify, Vercel).
2. В @BotFather: `/newbot` → создать бота, затем `/newapp` (или Bot Settings → Menu Button) и указать адрес приложения.
3. Глубокие ссылки работают через `startapp`: `https://t.me/<бот>/<приложение>?startapp=p_galantus`.

## Что осталось / нужно решить

- Оплата: подключить ЮKassa (на сайте уже ЮKassa) или Telegram Payments.
- Приём заказов: сейчас текст заказа копируется и открывается чат @straightlines. Если @straightlines — канал, а не личный аккаунт, лучше принимать заказы через бота.

- На сайте у «Джемпера «Татарник»» указан рост 1164 — в приложении так же, это стоит поправить на сайте.
